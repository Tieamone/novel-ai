# 《时光当铺》世界观设定

## 一、世界观

### 1. 基础设定
故事发生在与现实世界几乎相同的现代都市。表面上，这是一个普通的科技社会，拥有互联网、智能手机、现代医学等。但在人类认知的边缘，存在着一个被称为"缝隙"的超自然领域。当铺正是位于现实与缝隙之间的存在。

### 2. 记忆的本质
在这个世界中，记忆并非虚无缥缈的神经信号，而是一种可以被提取、储存、转移的实体物质。记忆具有以下特性：

- 可视化：在特定条件下，记忆会呈现为半透明的光球，颜色代表情感基调
  - 金色：幸福、温暖
  - 银色：平静、淡然
  - 红色：愤怒、激情
  - 蓝色：悲伤、忧郁
  - 黑色：恐惧、创伤
  - 紫色：复杂、矛盾

- 可量化：记忆有"重量"和"纯度"
  - 重量：代表记忆持续时间和强度
  - 纯度：代表记忆中情感浓度，纯度越高价值越大

- 可分离：记忆可以从意识中剥离而不影响基本人格，但核心记忆一旦失去会造成人格缺损

### 3. 时间的本质
时间在这个世界中可以被"实体化"，但条件极为苛刻。当铺是少数能够进行时间交易的场所。时间交易的特点：

- 时间必须"有主"：只能交易属于自己的生命时间
- 时间一旦典当，会从寿命中真实扣除
- 赎回时间需要支付额外代价
- 时间可以被"储存"，但无法被创造

### 4. 缝隙
缝隙是现实世界之外的空间夹层，当铺、以及其他一些超自然存在都栖息于此。缝隙的特点：

- 不受常规物理法则约束
- 时间流速与外界不同
- 普通人无法主动进入，只能被动"误入"
- 缝隙正在缓慢扩张，原因不明

## 二、地理设定

### 1. 城市：临渊市
故事发生的主要城市，一座拥有三百万人口的沿海中型城市。

城市布局：
- 老城区：老建筑密集，街道狭窄，当铺所在地
- 新城区：高楼林立，商业中心
- 港口区：货运码头，鱼龙混杂
- 大学城：高校聚集地，林深母校所在地
- 郊区：住宅区，有一些废弃工厂

### 2. 当铺位置
当铺位于老城区一条名为"回声巷"的死胡同尽头。特点：

- 巷口有一棵百年老槐树
- 当铺外观是一座两层老式洋房，民国时期风格
- 普通人路过时会下意识忽略，只有"有缘人"才能看见
- 当铺内部空间远大于外观，房间数量似乎随需求变化

### 3. 当铺内部结构
- 一楼：营业厅、鉴定室、等候区
- 二楼：员工休息区、档案室（存放典当记忆）
- 地下室：禁忌区域，存放危险或无法赎回的记忆，以及时间的实体储存空间
- 阁楼：老板娘的私人空间，无人知晓里面有什么

### 4. 其他重要地点
- 临渊市第一人民医院：林深曾工作的心理咨询室所在地
- 静湖公园：城市中央的人工湖，多个重要场景发生地
- 废弃纺织厂：郊区，与十年前失踪案有关
- 临渊大学：林深与陈烈的母校

## 三、物理法则

### 1. 基础物理
现实世界的物理法则正常运作，但缝隙空间有特殊规则。

### 2. 记忆物理

提取规则：
- 记忆提取需要当事人完全自愿，任何强迫都会导致记忆"破碎"
- 提取过程无痛，但会有短暂的恍惚感
- 提取后，当事人会忘记该段记忆，但可能保留模糊的情感残留

储存规则：
- 记忆必须储存在特制容器中，否则会逐渐消散
- 记忆可以无限期保存，但需要定期"维护"
- 记忆之间可能发生"渗透"，尤其是情感相似的记忆

转移规则：
- 记忆可以被他人"购买"并植入
- 植入记忆需要适应期，可能出现排斥反应
- 植入他人记忆不会改变人格，但会影响认知和情感

### 3. 时间物理

典当规则：
- 时间典当会真实减少寿命
- 典当时间有最低门槛：最少一天
- 典当时间后，当事人的生理年龄会相应变化

储存规则：
- 时间以"沙漏"形式储存
- 时间沙漏一旦破碎，时间会消散
- 时间可以被分割，但分割越细，价值损耗越大

### 4. 缝隙物理
- 空间非欧几里得：直线不一定最短
- 时间非线性：可能同时存在过去和未来的投影
- 因果律不稳定：某些行为可能产生不可预测的后果

## 四、力量体系与核心规则

### 1. 当铺核心规则

交易三原则：
- 等价交换：典当物的价值必须与换取之物相当
- 契约约束：交易一旦达成，不可单方面撤销
- 赎回期限：所有典当物都有赎回期限，逾期将永久归属当铺

价值评估体系：
典当物的价值由以下因素决定：
- 情感浓度：记忆中蕴含的情感强度
- 稀缺性：独一无二的记忆价值更高
- 时间跨度：持续时间越长价值越高
- 对当事人的重要性：越重要，价值越高

可典当之物：
- 记忆：任何一段个人记忆
- 时间：自己的生命时间
- 情感能力：如"爱的能力"、"恐惧的能力"等
- 机遇：未来可能发生的某个机遇
- 天赋：某种与生俱来的能力

可换取之物：
- 金钱：按记忆价值折算
- 机遇：改变命运的机会
- 遗忘：消除某段痛苦记忆
- 能力：临时或永久获得某种能力
- 时间：延长寿命（代价极高）
- 真相：获知某个答案

### 2. 当铺人员体系

老板娘：
- 当铺的所有者
- 拥有评估任何交易的能力
- 可以制定和修改当铺规则
- 来源成谜，似乎已存在很久

鉴定师：
- 负责评估典当物的价值
- 需要进入他人记忆进行"鉴定"
- 拥有进入缝隙的能力
- 现任鉴定师：林深

管家：
- 负责当铺日常运转
- 维护记忆储存系统
- 看守禁忌区域
- 现任管家：老周

### 3. 鉴定师能力体系

基础能力：
- 记忆共鸣：感知他人记忆的存在和情感基调
- 记忆进入：进入他人记忆进行鉴定
- 价值评估：判断记忆的交易价值

进阶能力：
- 记忆修复：修复破碎的记忆
- 记忆编织：在记忆中植入或修改细节
- 记忆回溯：追溯记忆的来源和变化

代价：
- 鉴定师每次进入他人记忆，都会承担"情感污染"的风险
- 过度使用能力会导致自我记忆混乱
- 最终可能失去区分"自己"和"他人"的能力

### 4. 赎回机制

正常赎回：
- 在期限内支付约定代价即可赎回
- 赎回后记忆会完整归还

逾期处理：
- 逾期典当物永久归属当铺
- 当铺可以将其出售给他人
- 原主人会永久失去该部分

特殊赎回：
- 某些情况下，可以通过完成特定任务赎回
- 任务难度与典当物价值相关
- 失败可能导致额外损失

### 5. 禁忌与惩罚

绝对禁忌：
- 不可强迫他人交易
- 不可交易他人的记忆或时间
- 不可试图欺骗当铺
- 不可进入禁忌区域

违反禁忌的后果：
- 轻则失去交易能力
- 重则被剥夺所有记忆
- 最严重者会被"放逐"到缝隙深处

### 6. 当铺的起源与秘密

表层历史：
- 当铺存在至少两百年
- 历任老板娘似乎都是同一人
- 鉴定师更替频繁，通常因无法承受能力代价而离开

深层秘密（故事后期揭露）：
- 当铺最初由一个想要挽回遗憾的人创造
- 老板娘是第一个交易者，典当了"死亡"本身
- 当铺存在的真正目的：收集足够多的"遗憾"，最终实现一次逆转时间的机会
- 林深的记忆与这个终极目的有关
