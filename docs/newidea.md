# 竞品优化引入方案

> 分析日期：2026-05-19
> 分析对象：Narcooo/inkos（6.2k⭐）、NousResearch/autonovel（952⭐）、RhythmicWave/NovelForge（847⭐）
> 核心原则：**只引入与当前 Python CLI 技术栈兼容、且能直接提升输出稳定性的优化点**

---

## 一、筛选逻辑

每条优化点从三个维度打分（满分 3 分）：

| 维度 | 说明 |
|------|------|
| **技术兼容性** | 能否在现有 Python CLI 架构上实现，不需要重写核心 |
| **输出稳定性** | 是否直接提升章节质量的一致性和可靠性 |
| **实现成本** | 工作量评估（低 3 分 = 几天，中 2 分 = 1-2 周，高 1 分 = 月级） |

**通过线**：技术兼容性 ≥ 2 且 输出稳定性 ≥ 2。

## 二、逐个评估

### ✅ 建议采纳（全部通过筛选）

---

#### 1. 文法指纹分析（来源：inkos）

| 维度 | 评分 | 理由 |
|------|:---:|------|
| 技术兼容性 | 3 | 纯 Python + 复用现有 `call_author_api()`，不引入新依赖 |
| 输出稳定性 | 3 | 自动提取参考文本的句长分布、词频、节奏特征 → 注入写手 prompt → 全书语调一致 |
| 实现成本 | 2 | 需新增 `style_analyzer.py`，约 200-300 行 + prompt 设计 |

**核心思路**：
- 用户提供参考文本（某位作者的章节/你喜欢的小说片段）
- AI 提取：句长分布、高频词/低频词、对话比例、段落节奏、修辞偏好
- 生成可复用的"文法指纹"配置文件，注入到 `build_full_chapter_prompt()` 中
- 比现有的 9 种固定风格模板更精准，且可叠加

**为什么能提升稳定输出**：
现有风格模板是"泛化"的（如"爽文宗师"），但每个作者的爽文风格都不同。文法指纹让 AI 精确模仿特定作者的语感，减少风格漂移。

**实现路径**：
```
用户上传 reference.txt
  → style_analyzer.py 调用 call_author_api() 提取指纹
  → 生成 data/{小说名}/style_fingerprint.json
  → writer.py 的 build_*_prompt() 读取并注入
```

#### 2. Anti-Slop 三层升级（来源：inkos + autonovel）

| 维度 | 评分 | 理由 |
|------|:---:|------|
| 技术兼容性 | 3 | 扩展现有 `_rule_based_ai_check()`（37 条正则），新增 prompt 层检测 |
| 输出稳定性 | 3 | 词级→结构级→跨章级，逐层过滤 AI 痕迹，质量层层加码 |
| 实现成本 | 2 | 第一层扩展正则、第二层新增 prompt、第三层新增统计逻辑 |

**三层体系设计**：

| 层级 | 名称 | 检测方式 | 检测内容 |
|------|------|----------|----------|
| L1 词级 | Mechanical Slop | 正则 + 频率统计 | 现有 37 条正则 + 词汇疲劳度（同词跨章频率 > 阈值）+ cliché 词库 |
| L2 结构级 | Anti-Patterns | LLM 审稿 | "先总结后展开"、"三段式收尾"、"强行正能量升华"、"无故内心独白收尾" |
| L3 跨章级 | Cross-Chapter | 统计 + LLM | 连续 N 章句式单调性、情绪曲线平坦、对话/叙述比例失衡 |

**为什么能提升稳定输出**：
现有 37 条正则只能抓"词级"问题，但 AI 的结构性问题（如每章都以"XXX心想"结尾）正则抓不到。三层体系逐级递进，对 AI 痕迹形成立体防御。

**实现路径**：
- L1：在 `_rule_based_ai_check()` 中新增 15-20 条正则 + 跨章词频统计
- L2：在 `review_chapter()` 的 REVIEWER_SYSTEM 中新增 anti-pattern 检测维度
- L3：在 `show_progress()` 或新增 `_check_cross_chapter_quality()` 中实现

#### 3. 输入治理控制面（来源：inkos）

| 维度 | 评分 | 理由 |
|------|:---:|------|
| 技术兼容性 | 3 | 纯文件读写 + prompt 注入，零新依赖 |
| 输出稳定性 | 3 | 从"每章独立目标"升级为"长期意图+短期焦点"双层控制，减少剧情漂移 |
| 实现成本 | 3 | 改动极小：新增 2 个 .md 文件 + 修改 prompt 拼接逻辑 |

**核心思路**：
- `author_intent.md`：这本书长期想成为什么（基调、主题、不想变成什么样）
- `current_focus.md`：最近 1-3 章要把注意力聚焦在哪里（当前弧线的核心冲突）

**为什么能提升稳定输出**：
现有系统每章只有 `plot_goal` + `emotion_tag`，所有章之间是孤立的。作者写到第 50 章时可能已经忘了第 10 章埋下的基调。"长期意图"文件让每章写作时都重新对齐创作初心。

**实现路径**：
```
1. 新建小说时生成 author_intent.md 和 current_focus.md 模板
2. chapters_menu 新增选项"编辑创作意图"
3. build_full_chapter_prompt() 和 build_writer_prompt() 读取两个文件注入 prompt
4. _save_chapter_memory() 完成后询问是否更新 current_focus.md
```

#### 4. 平台期检测（来源：autonovel）

| 维度 | 评分 | 理由 |
|------|:---:|------|
| 技术兼容性 | 3 | 纯逻辑改动，在 `write_and_review()` 内部增加评分趋势判断 |
| 输出稳定性 | 3 | 避免无效重试浪费 token，同时避免"越改越差" |
| 实现成本 | 3 | 改动极小：约 20 行代码 |

**核心思路**：
- 在 `write_and_review()` 的重试循环中记录最近 2-3 轮的评分
- 如果连续 2 轮评分无显著提升（差值 < 阈值），提前终止修订 → 强制通过
- 避免当前"固定 3 轮重试、越改越差还不自知"的问题

**为什么能提升稳定输出**：
不是所有问题都能靠重试解决。如果 AI 反复改但评分不动，说明是任务卡/大纲层面的问题，继续重试白白浪费 token 且可能引入新问题。

**实现路径**：
```python
# 在 write_and_review() 的 retry 循环中
scores_history = []  # 最近 N 轮评分
for attempt in range(max_retry):
    ...
    result = review_chapter(...)
    current_score = result.get("total_score", 0)
    scores_history.append(current_score)
    
    if len(scores_history) >= 3:
        # 计算趋势：最近 3 轮评分波动 < PLATEAU_THRESHOLD
        if max(scores_history[-3:]) - min(scores_history[-3:]) < 5:
            print("[平台期] 评分连续3轮无显著提升，停止重试→强制通过")
            break
```

#### 5. 对抗性精简（来源：autonovel）

| 维度 | 评分 | 理由 |
|------|:---:|------|
| 技术兼容性 | 3 | 复用 `call_reviewer_api()`，新增一个审稿维度 |
| 输出稳定性 | 2 | 提升文字密度，减少读者跳读冲动，但属于锦上添花 |
| 实现成本 | 2 | 需新增一个审稿 prompt 维度 + 应用逻辑 |

**核心思路**：
- 在审稿阶段增加"冗余检测"维度
- AI 标注：哪些段落可裁切、哪些对话可精简、哪些描写对情节无贡献
- 用户可选择性地应用裁切建议（而非自动裁切，保留控制权）

**为什么能提升稳定输出**：
AI 生成容易"水字数"——大段无用描写、重复的心理活动、唠嗑式对话。对抗性精简是 word_max 之外的"质量上限"，让章节在字数内更紧凑。

**实现路径**：
```
review_chapter() 新增 "redundancy" 维度
  → AI 输出可裁切段落列表 + 裁切理由
  → 返回结果中增加 "cut_suggestions" 字段
  → write_and_review() 在 pass 后询问是否应用裁切
```

## 四、预期效果

实施以上 5 个优化后，预期达到：

1. **风格一致性** ↑↑：文法指纹 + 输入意图控制 = 全书语调不漂移
2. **AI 痕迹** ↓↓：三层 Anti-Slop = 词/结构/跨章全方位去 AI 味
3. **文字密度** ↑：对抗性精简 = 同字数内信息量更大
4. **Token 浪费** ↓：平台期检测 = 无效重试减少 30-50%
5. **剧情连贯性** ↑：长期意图 + 短期焦点 = 每一章都知道"为什么写"
