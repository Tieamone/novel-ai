# 本地小说写作工作台

运行 `python main.py` 会启动工作台并打开默认浏览器。使用 `python main.py --cli` 进入原有命令行菜单。首次安装步骤见 [README](../README.md)。浏览器连接本机的 Waitress 服务，Flask 提供 JSON 接口，Vue 页面与接口共用地址。模型请求在 Python 中执行，继续使用项目根目录的 `.env` 和现有配置。

## 写作任务

每次只在工作台运行一个写作或编辑任务。单章和批量生成共用 CLI 的章节认领、审稿、记忆提取和导出流程。需要决定是否局部修订、换模型、裁切段落时，任务面板会显示对应的操作。点击停止会在下一处可中断的步骤退出，并尝试恢复章节状态。任务记录在服务运行期间保留，写作尝试历史存放在原有小说库中。

当前任务执行中或等待确认时，新建和删除表单会提示原因。点击「处理当前任务」可以确认或停止任务，再用「返回表单」继续提交。后台操作失败时，原表单保留已填内容和具体错误。小说策划失败后，可以用同一书名重新提交并继续策划。

删章前会核对整个范围。存在缺失章节或正在写作的章节时，整段都保留。删除成功会清理正文、逐章摘要和 TXT 导出，复位可定位的伏笔状态与现有任务卡。生成从最早的未完成章节继续。

浏览书库和章节时使用只读连接。旧小说如果缺少任务卡字段或写作历史等表，首次需要写入时会先询问是否运行项目已有的兼容迁移。

## 页面、接口和模型调用

| 页面或操作 | 实际读取或写入 |
| --- | --- |
| 书库、章节、任务卡、伏笔和创作资料 | 书库从 `/api/bootstrap` 枚举已有小说。进入业务页面重新请求 `/api/book`，由 Python 读取 SQLite 与资料文件。打开正文时单独请求 `/api/chapter/<章号>`。 |
| 断点管理 | 进入或刷新页面时读取异常任务，并通过 `/api/checkpoint/<章号>` 读取写作历史和节拍。重置任务、清空正文、清除节拍都走 CLI 共用函数。 |
| 模型与费用 | `/api/models` 按 24 小时缓存检查百炼额度，再读取模型列表和本次会话的费用、失败与切换统计。“立即刷新免费额度”通过受会话令牌保护的 `POST /api/models/refresh` 强制查询，只更新候选。点击「验证并保存」才会向服务商发送最小请求。 |
| 建书、导入、章节生成和审稿恢复 | `/api/jobs` 启动后台任务，调用 CLI 共用的策划、生成和审稿函数。任务完成后重新读取数据库。 |
| 任务卡、伏笔、风格、创作意图、删除和导出 | `/api/jobs` 执行相应的 Python 函数。变更写入 SQLite 或小说目录，TXT 导出写入项目导出目录。生成伏笔建议和文法指纹时还会调用作者模型。 |

验证按所选角色执行，服务商和模型都相同时共用一次请求。页面显示回复、耗时、失败原因或缺少密钥的状态。全部通过后才应用模型变更，作用范围为本次 Python 会话。文法指纹只有在模型返回有效语义分析后才写入。

未通过或审核服务异常的稿件保留为「审稿失败」。自动生成从最早的未完成章节开始。默认停止。显式选择恢复菜单的强制导出，或配置 `novel.on_review_exhausted: force_and_flag` 后，内容审核不达标可强制通过。服务、记忆或导出异常仍会中断，批次会列出已完成的强制通过章节。只有已审核或强制通过的正文可以单章导出或批量导出。记忆提取或导出中断后，可通过「生成章节」补做收尾。

旧版导出如果曾使用去掉前后下划线或点的目录名，可从当前小说重新导出到完整书名目录。历史文件保留在原位置。大纲伏笔依据专项审稿的逐项结论推进。候选 ID 与引文需要通过校验。作者可在伏笔管理中复核未推进的条目。

## 本地回归

```powershell
.\venv\Scripts\python.exe -B -m unittest discover -s tests -v
npm.cmd --prefix web run build
```

接口测试使用独立临时目录和模拟模型响应，覆盖任务中途确认、停止与重试、导出、模型去重和失败反馈，以及现有菜单的数据库操作。实际模型连通性可在「模型与费用」直接验证，只发送简短验证提示，调用费用由当前模型决定。

## 页面状态回归

运行 `node web/check-state.mjs` 验证切章清空、请求乱序、断点输入变化、切书草稿隔离、任务等待时保留表单及删章失败后重试。测试使用 Vue 响应式运行时和模拟接口。切换页面会关闭编辑弹窗，切换小说会关闭针对旧书的编辑弹窗并清除旧书的未保存草稿。

## 遗留任务和旧书体检

生成遇到「进行中」任务时会先请求确认。已审正文补做记忆和导出，未审稿重置后重新生成。确认前请检查没有另一个命令行进程在写同一本书。成功生成后可在「创作资料」更新当前焦点。

在「伏笔」页运行「只读体检」可检查摘要、导出、任务状态和旧伏笔。选「整理旧伏笔」后，输入要归档的 ID，核对预览并确认。数据库备份放在导出根目录的 `.book-backups` 下。归档保留原记录，写作时跳过这些条目。大纲伏笔回滚按当前计划章号，手工改过章号的历史记录需复核。
