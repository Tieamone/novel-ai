# 本地小说写作工作台

运行 `python main.py` 会启动工作台并打开默认浏览器。使用 `python main.py --cli` 进入原有命令行菜单。首次安装步骤见 [README](../README.md)。浏览器连接本机的 Waitress 服务，Flask 提供 JSON 接口，Vue 页面与接口共用地址。模型请求在 Python 中执行，继续使用项目根目录的 `.env` 和现有配置。

## 菜单对应关系

| CLI 功能 | 浏览器位置 |
| --- | --- |
| 主菜单 1 新建小说或文本导入 | 侧栏的新建、导入，后续策划选择在任务面板完成 |
| 主菜单 2 继续已有小说 | 侧栏的小说书库 |
| 主菜单 3 删除小说 | 侧栏底部，需输入书名和 YES |
| 主菜单 4、章节 11 模型配置 | 模型与费用，验证后应用到本次会话 |
| 章节 1、2 自动生成和批量生成 | 章节与审稿顶部 |
| 章节 3、4 导出和章节列表 | 章节目录，正文右上也可单章导出 |
| 章节 5、13 查看和编辑任务卡 | 章节任务卡 |
| 章节 6 更换写作风格和参考文本 | 创作资料 |
| 章节 7、12 费用、失败和切换统计 | 模型与费用 |
| 章节 8 恢复审稿失败 | 打开审稿失败的章节后选择恢复方式 |
| 章节 9、10 单章删除和范围删除 | 正文右上、章节目录底部 |
| 章节 14、15 伏笔健康度和大纲伏笔 | 伏笔管理 |
| 章节 16 异常任务、重置、历史、重写和节拍 | 断点管理 |
| 章节 17 创作意图和当前焦点 | 创作资料 |

## 写作任务

每次只在工作台运行一个写作或编辑任务。单章和批量生成共用 CLI 的章节认领、审稿、记忆提取和导出流程。需要决定是否局部修订、换模型、裁切段落时，任务面板会显示对应的操作。点击停止会在下一处可中断的步骤退出，并尝试恢复章节状态。任务记录在服务运行期间保留，写作尝试历史存放在原有小说库中。

浏览书库和章节时使用只读连接。旧小说如果缺少任务卡字段或写作历史等表，首次需要写入时会先询问是否运行项目已有的兼容迁移。

## 本地回归

```powershell
.\venv\Scripts\python.exe -B -m unittest discover -s tests -v
npm.cmd --prefix web run build
```

接口测试使用独立临时目录和模拟模型响应，覆盖任务中途确认、停止与重试、导出以及现有菜单的数据库操作。验证真实模型时使用测试小说和已配置的密钥，调用费用由当前模型决定。
